# Імітаційне моделювання бізнес-процесів контакт-центру

Настільний застосунок (Python + Tkinter + Matplotlib) для курсової роботи
«Імітаційне моделювання бізнес-процесів для сервіс-орієнтованої інформаційної системи організації».

Бізнес-процес: **надходження виклику → черга (FIFO) → оператор → постобробка → контроль SLA**.
Модель — дискретно-подієва система масового обслуговування M(t)/G/N, відкалібрована за журналом
`simulated_call_centre.csv` (51 708 викликів, 261 робочий день 2021 р.).

## Запуск

```bash
pip install -r requirements.txt
python main.py                 # автоматично завантажує data/simulated_call_centre.csv
python main.py шлях/до/файлу.csv   # або .zip з CSV
```

Потрібен Python 3.10+ (у складі є tkinter; на Linux: `sudo apt install python3-tk`).

## Структура

| Файл | Призначення |
|---|---|
| `app/engine.py` | Дискретно-подієвий рушій (календар подій на heapq, нестаціонарний пуассонівський потік, черга FIFO, змінний штат, терпіння клієнтів, реплікації, 95% ЦІ) |
| `app/queueing.py` | Аналітична модель M/M/N (Erlang C): очікування, SLA, підбір штату, теоретична функція розподілу |
| `app/data.py` | Читання журналу (CSV/ZIP), оцінка кількості операторів, підгонка розподілів, тренд, текст висновків |
| `app/experiments.py` | Валідація, підбір штату, стрес-тест, прогноз, погодинний розклад |
| `app/export.py` | Експорт у Excel (9 аркушів) та CSV |
| `app/gui/*` | Вкладки інтерфейсу, теми, графіки |

## Вкладки

1. **Дані** — журнал дзвінків, фільтри, порушення SLA, KPI.
2. **Аналіз даних** — ідентифікація моделі: закон обслуговування, пуассонівськість потоку, тренд навантаження, кількість операторів.
3. **Модель** — параметри, схема бізнес-процесу, миттєва оцінка Erlang C, запуск (F5).
4. **Результати** — KPI з довірчими інтервалами, 6 графіків, порівняння з фактом, висновок, експорт.
5. **Валідація** — факт ↔ імітація ↔ Erlang C по місяцях (MAPE, покриття інтервалу, тест Колмогорова–Смирнова).
6. **Сценарії** — підбір штату (з вартістю), стрес-тест (штат × навантаження), прогноз на місяці вперед, погодинний розклад.
7. **Порівняння** — кілька збережених запусків поруч.
8. **Анімація дня** — покадрове відтворення одного робочого дня.

Гарячі клавіші: F5 — запуск, Ctrl+O — відкрити, Ctrl+E — Excel, Ctrl+T — тема.

## Ключові результати аналізу даних

* 4 оператори (максимум одночасних розмов), одна черга FIFO, без відмов клієнтів.
* Тривалість розмови ≈ експоненційна (середнє 299 с, CV = 1,00).
* Інтенсивність зростає ≈ +11,6 викликів/день щомісяця (R² = 0,97): 143 → 272 викл./день.
* SLA (очікування ≤ 60 с) падає з 97,5% (січень) до 83,5% (грудень).
* Особливості журналу: перший дзвінок кожного дня о 08:00:00; дзвінки, не завершені до 18:00, відсутні (цензурування) — враховано при оцінці λ(t).
* Валідація (5 прогонів на місяць; при іншій кількості значення трохи зміняться): факт потрапляє в 95% інтервал імітації у 90% випадків, MAPE за SLA і завантаженням < 2%.
